# Tree Module Components

L2 Member List for the Knowledge Tree UI components.

## Members
- [TreeContainer.tsx](file:///home/aa/Park/tree-fusion-dairy/components/tree/TreeContainer.tsx): 3-column layout container for the Tree app.
- [TreeSidebar.tsx](file:///home/aa/Park/tree-fusion-dairy/components/tree/TreeSidebar.tsx): Document navigation and management sidebar.
- [OutlineTree.tsx](file:///home/aa/Park/tree-fusion-dairy/components/tree/OutlineTree.tsx): Recursive root for the outliner with DnD context.
- [OutlineNode.tsx](file:///home/aa/Park/tree-fusion-dairy/components/tree/OutlineNode.tsx): Single interactive item in the tree (DnD sortable, keyboard, toolbar).
- [UnifiedToolbar.tsx](file:///home/aa/Park/tree-fusion-dairy/components/tree/UnifiedToolbar.tsx): Floating operation/format toolbar UI component.
